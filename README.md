# 心语岛 - 情绪疏导、树洞倾听与真人陪伴微信小程序

心语岛（YeIsland）是一款主打**匿名、真人、低成本**的微信小程序。如果你感到情绪低落、失恋想找人梳理，或者只是深夜emo想找个活人说话，心语岛提供了一个没有社交压力、不被评判的倾诉空间。

## 核心功能

| 功能模块 | 服务内容 | 适用场景 |
| :--- | :--- | :--- |
| **匿名树洞** | 随时写下心事，可以选择公开或私密，获得陌生人的善意回应。 | 深夜emo、只想说两句不想被熟人看到 |
| **真人倾听者** | 1对1匿名倾诉，倾听者不是咨询师，而是愿意认真听你说话的过来人或受过倾听训练的普通人。支持文字和语音。 | 失恋想找人梳理、感情问题想吐槽、日常压力大想有人陪聊 |
| **陪伴聊天** | 不预设话题，不急于给你“讲道理”或“灌鸡汤”，只是陪伴你度过难熬的时刻。 | 不会恋爱想找过来人聊、只是想找个活人待一会儿 |
